# Lorax Hotline

Initial Bun + TypeScript scaffold for Lorax Hotline. Feature phases are intentionally not implemented yet.

## Setup

1. Install [Bun](https://bun.sh/).
2. Install dependencies with `bun install`.
3. Copy `.env.example` to `.env` and fill in credentials when needed. Keep `DRY_RUN=true` unless explicitly testing real outbound behavior.
4. Start the scaffold with `bun run dev`.

Phase 0 provides the runnable baseline. See `claude.md` for the phased implementation plan and project constraints.
